# Image Audit

Every image in `public/images/`, what's wrong with it, and the proposed naming
convention. Generated by checksumming all files, then cross-referencing against
`src/` for actual usage.

The real problem isn't disk space, it's that **40 files are the same photographs
reused under different names across unrelated pages.** A visitor who browses the
security page, then the access-control page, then the Pacific Horizon case study
sees the identical photograph three times presented as three different things.
For a company selling bespoke work, that is the most damaging content issue on the
site — more than any animation in these docs.

## 4. Naming convention

### Current problems

| Problem | Example |
| --- | --- |
| Folder ≠ route | `solutions/lighting/` serves `/lighting-control-systems/` |
| WordPress slug cruft in folders | `brands/lutron-2/`, `brands/josh-ai-2/` vs `brands/savant/` |
| Meaningless sequence names | `feature-1.webp` × 12 folders, `step-1.webp`, `gallery-*.webp` |
| Redundant folder prefix in filename | `design-partners/design-partners-architects.webp` |
| Flat + nested copies of one set | `home/inspiration-malibu.webp` **and** `home/inspiration/malibu.webp` |
| Mixed logo formats | 2 SVG, 4 WebP |

### Proposed convention

```
public/images/<page-or-route>/<section>-<subject>.webp
```

- **Folder = the route slug**, exactly. `/lighting-control-systems/` →
  `solutions/lighting-control-systems/`.
- **Filename = section + subject**, never an index. `feature-1.webp` →
  `capability-one-touch-control.webp`.
- **Never repeat the folder name in the filename.**
- **Lowercase, hyphenated, `.webp`** — except logos, which are `.svg`.
- Shared/cross-page assets live in `images/shared/`.

## 5. Technical follow-ups

1. **No responsive images anywhere.** Every image is a plain `<img>` with one
   source. A 1586×992 hero ships at full size to a phone. Switch to Astro's
   `<Image />` / `<Picture />` and let it emit `srcset` — the biggest performance
   win available, and it needs no new artwork.
2. **Missing width/height on many images**, which causes layout shift. `PostCard`
   and `ProcessSteps` set them; the solution and brand pages mostly don't.
3. **Re-source the four raster logos as SVG.** All four manufacturers publish
   brand kits.
4. **`loading="lazy"` is applied inconsistently** — some below-fold images load
   eagerly. Worth one sweep.
5. **No `public/images/forms/`** content — the folder exists and is empty. Delete
   it or use it.
